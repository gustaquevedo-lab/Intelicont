# Principios de UX — InteliCont

1. Teclado primero. Atajos en toda acción frecuente. Command palette (Cmd/Ctrl+K).
2. Edición tipo hoja de cálculo en grillas. Tab/Enter/Shift+Enter intuitivos.
3. Drill-down universal: todo número clickeable hasta el asiento origen.
4. IA con explicación: confianza, razón, fuente. Aprobar/rechazar/editar siempre visible.
5. Cierre como checklist viva con validaciones automáticas.
6. Estados claros: borrador, posteado, reversado, ajustado.
7. Multi-empresa con switcher Cmd+E. Indicador de empresa activa siempre visible.
8. Errores fiscales muestran regla violada y link a docs/FISCAL_PY_RULES.md.
9. Optimistic UI, loaders solo si > 300ms.
10. WCAG AA, dark mode nativo, alta densidad para power users.
