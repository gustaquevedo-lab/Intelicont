# IA y aprendizaje

Objetivo
- Definir la capa de IA, con capacidad de ingestión, sugerencia de cuentas, y propuesta de reconciliación; mantener loop humano en la decisión.

Entregables
- IA skeleton: interfaces ingestDocument, suggestAccount, proposeReconciliation.
- ai_decisions: schema para registrar decisiones IA (input, output, confidence, accepted, accepted_by).
- UI de revisión de IA para aprobar/rechazar propuestas.
- Provisiones de logging/ scoring para aprendizaje posterior.

Historias
- IA-01: Definir interfaces y proveedor IA por defecto (fake/free) para MVP.
- IA-02: Registro de ai_decisions y auditoría.
- IA-03: UI de revisión de IA con razonamientos y fuentes.

Criterios de aceptación
- Interfaces IA definidas y funcionales (sin implementación compleja).
- ai_decisions se almacenan y se pueden consultar.
- UI de revisión de IA disponible y usable.

Notas
- En MVP usar un proveedor IA gratuito o backend open-source cuando sea posible; el código debe permitir swap sin cambios en dominio.
